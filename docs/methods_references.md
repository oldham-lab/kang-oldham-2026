# Methods References — AI-assisted gene curation (Table S15)

Reference entries for the external models and databases cited in the AI-powered
literature-review methods blurb.

1. **Claude Sonnet 4.6 / Claude Code** — Anthropic. *Claude (Sonnet 4.6)*
   [large language model]. Anthropic, 2026. https://www.anthropic.com/claude.
   Accessed via Claude Code (https://www.anthropic.com/claude-code).

2. **OMIM** — Amberger JS, Bocchini CA, Scott AF, Hamosh A. OMIM.org: leveraging
   knowledge across phenotype–gene relationships. *Nucleic Acids Res.*
   2019;47(D1):D1038–D1043. https://omim.org.

3. **Open Targets Platform** — Ochoa D, Hercules A, Carmona M, et al. The
   next-generation Open Targets Platform: reimagined, redesigned, rebuilt.
   *Nucleic Acids Res.* 2023;51(D1):D1353–D1359. https://platform.opentargets.org.

4. **ClinVar** — Landrum MJ, Lee JM, Benson M, et al. ClinVar: improvements to
   accessing data. *Nucleic Acids Res.* 2020;48(D1):D835–D844.
   https://www.ncbi.nlm.nih.gov/clinvar.

5. **Alzforum** — Alzforum: Networking for a Cure. Cambridge (MA):
   FBRI / Biomedical Research Forum LLC. https://www.alzforum.org.
