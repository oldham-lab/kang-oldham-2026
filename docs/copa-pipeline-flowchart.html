Bioinformatics Workflow · run order

COPA / Consensus-analysis Pipeline

Derive consensus co-expression modules from a batch-corrected bulk human-cortex RNAseq megaset, then project those modules onto single-nucleus datasets to ask which modules are differentially co-expressed in disease (AD, SCZ) vs control — and which findings are conserved across datasets. Spans the COPA method package and the Consensus-analysis analysis repo.

Raw cohort RNAseq→ ComBat megaset→ Consensus modules→ SN projection→ Compare & conserve→ Figures

Caveats carried from the source docs

  • Hardcoded paths. Most scripts source() and read/write absolute paths (~/!softlinks/…, ~/RNAseq_megaset/, /mnt/bdata/…); some source() lines are stale relative to files' current locations.
  • Partially stale wrapper.R. COPA_compare() still source()s files moved to deprecated/ — the live comparison path calls the standalone engine directly, bypassing COPA_compare().
  • Commented-out steps. Several wrapper steps (create_bulk_cor_obj, create_proj_obj, plot_net_snapshots, Oldham/SN GSHG) are off by default — the live path is narrower than the function bodies suggest.
  • "claude_input" naming (e.g. 5-SEAAD2024_DE_claude_input.R) marks a trimmed standalone script prepared as context — not a script that consumes model output.
